# NourishDay & iTongue interactive presentation

Published at https://jiacheng.website/slides/nourishday-itongue/ (English by default); Chinese: https://jiacheng.website/slides/nourishday-itongue/#zh/1. The former `/roadshow/` URLs redirect here.

Jiacheng Xie. Six-page academic-style product presentation for investors and potential partners. The deck uses a fixed 16:9 desktop stage for browser fullscreen, with a scrolling responsive layout on narrow screens. The cover uses the official NourishDay and iTongue icons, the presenter's name and October 2026. The overview leads to separate background and demonstration pages for each project.

Public controls: persistent Home / Overview / NourishDay Background / NourishDay Demo / iTongue Background / iTongue Demo navigation, English/中文 switching, fullscreen, previous/next and direct hash links. Keyboard: Left/Right or Space navigate; 1–6 jump to pages; Home returns to the cover; O opens the overview; L changes language; F requests fullscreen. Speaker Notes and Start Timer are intentionally absent from the public page.

The single self-contained HTML embeds all project-owned demonstration assets and uses no analytics, CDN, login, API requests or private patient data. Responsive CSS, viewport fallbacks, reduced-motion handling, focus-visible states, and standard/WebKit fullscreen support target modern Chrome, Edge, Firefox and Safari. The NourishDay background cites current CDC, WHO and ACSM sources. Page 4 has a playable three-step workflow using real app screens and a reviewed portion calculator. Page 5 separates iTongue's capture background from its demonstration, and page 6 toggles synthetic capture and a clearly labeled undeployed local segmentation prototype.

Editable build sources and evidence: `TCM_Calendar/output/presentations/dual-projects-batch-01/.build` in the owner's local working package. Roll back by reverting the scoped website publication commit. No homepage links or unrelated product pages are modified.
